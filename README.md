# ✅ Flask To-Do App

A clean, modern **To-Do List web application** built with **Flask** and **SQLite**, featuring task management, filters, dark mode, due dates, and a polished user experience.

This project was built step-by-step as a hands-on way to learn **full-stack web development with Python**.

---

## ✨ Features

- ➕ Add tasks with optional **due dates**
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed / active
- 🗑️ Delete tasks with confirmation popup
- 🔍 Filter tasks:
  - All
  - Active
  - Completed
- 📊 Live task counters
- 📅 Due date highlighting:
  - 🔴 Overdue tasks
  - 🟠 Tasks due today
- 🌙 Dark mode (saved in browser)
- ⌨️ Keyboard friendly (Enter to add, ESC to cancel edit)
- 💾 Persistent storage using SQLite

---

## 🛠️ Tech Stack

- **Backend:** Python, Flask  
- **Database:** SQLite + SQLAlchemy  
- **Frontend:** HTML, CSS, Jinja2  
- **Server:** Gunicorn  
- **Deployment:** Render
